# Laboratory Work 1: Landing Page Markup and Styling

## Overview
The goal of this laboratory work is to develop a static multi-section landing page using semantic HTML5 and modular CSS based on a provided design layout.

## Requirements
- Use semantic HTML5 elements (`header`, `main`, `section`, `footer`, `nav`).
- Structure CSS into modular files (global styles, header, hero section, story section, reviews, footer).
- Implement layout positioning using modern CSS techniques (Flexbox, CSS variables).
- Maintain clean code organization with separate folders for data/pages, styles, and assets.
- Ensure correct typography, colors, and layout alignment according to the design template.

## Project Structure
- `data/index.html` - Main landing page markup
- `css/` - Modular stylesheet directory
  - `global.css` - Base resets, fonts, and global variables
  - `header.css` - Navigation bar and header layout
  - `hero.css` - Hero section styling
  - `storie.css` - Story / About section layout
  - `reviews.css` - Customer reviews and ratings
  - `footer.css` - Footer elements and links
  - `style.css` - Main stylesheet combining modular files
- `assets/` - Image and icon assets

## How to Run
Open `data/index.html` in any modern web browser or run via Live Server.
